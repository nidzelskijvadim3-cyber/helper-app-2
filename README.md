# Мой помощник, версия 2

Переменные окружения (на Vercel или в файле .env.local):
- ANTHROPIC_API_KEY: ключ Claude API (console.anthropic.com). Если задан — Claude основной ИИ
- ANTHROPIC_MODEL: модель Claude, по умолчанию claude-haiku-5-5
- DEEPSEEK_API_KEY, DEEPSEEK_MODEL: DeepSeek (по умолчанию deepseek-flash)
- GEMINI_API_KEY, GEMINI_MODEL: Gemini
- AI_ORDER: порядок ИИ, по умолчанию claude,deepseek,gemini. Используются только ИИ с заданным ключом
- APP_PASSWORD: пароль приложения (защищает ИИ и синхронизацию)


## Документы и резервные копии
- Документы (зошиты, дошки, фото, сканы, PDF) сохраняются в IndexedDB текущего браузера на устройстве; при включённой синхронизации страницы уходят на сервер по одной.
- **Импорт PDF** — «Створити» → «Імпорт PDF» (или PDF, выбранный через «Імпорт фото»). До 50 страниц и 50 МБ на файл; если страниц больше, приложение предлагает выбрать диапазон (до 50 за раз). Каждая страница сохраняется как изображение (ширина ~1600 px, JPEG 0.75) — поверх работают перья, выделитель, ластик, лассо, миниатюры. Зашифрованные (с паролем) и повреждённые PDF не импортируются, приложение говорит почему.
- **Текст PDF** извлекается при импорте и хранится в документе (не рисуется). Он используется в поиске по Матеріалам (с переходом на найденную страницу), в Помічнику и в тестах «З матеріалу»: ИИ получает текст страниц, а изображение — только для страниц без текста (скан внутри PDF) или с вашими пометками. Для PDF можно выбрать до 10 страниц (для остальных материалов — до 4).
- Размер: страница с плотным текстом занимает в хранилище ~0,7 МБ, разреженная — ~0,1 МБ; 50 плотных страниц ≈ 35 МБ (это же попадает в резервную копию и синхронизацию).
- **Экспорт в PDF** — в редакторе «⋯» → «Експорт у PDF» или в меню материала. Все страницы, текущая или диапазон; каждая страница — отрисованная картинка (фон/шаблон/изображение + штрихи, фигуры, текст). Размер страницы: у импортированного PDF — исходный, у зошита — ширина A4, у дошки — по её пропорциям. Текст в экспортированном файле не выделяется и не ищется (страницы — изображения).
- Скачивание — обычной ссылкой; если браузер умеет делиться файлами (iPhone/iPad), есть «Поділитися» → «Зберегти у Файли», а на iOS ещё «Відкрити в новій вкладці».
- pdf.js worker лежит в `public/pdf.worker.min.mjs` (копия `pdfjs-dist/legacy/build`, обновляется скриптом `postinstall`; версия должна совпадать с `pdfjs-dist`).
- Используйте «Резервна копія», чтобы выгрузить все документы (включая PDF со страницами и текстом) в JSON, и «Відновити», чтобы добавить их обратно.
- Резервная копия не является облачной синхронизацией: храните её отдельно от устройства.
