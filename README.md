# Мой помощник, версия 2

Переменные окружения (на Vercel или в файле .env.local):
- ANTHROPIC_API_KEY: ключ Claude API (console.anthropic.com). Если задан — Claude основной ИИ
- ANTHROPIC_MODEL: модель Claude, по умолчанию claude-haiku-5-5
- DEEPSEEK_API_KEY, DEEPSEEK_MODEL: DeepSeek (по умолчанию deepseek-flash)
- GEMINI_API_KEY, GEMINI_MODEL: Gemini
- AI_ORDER: порядок ИИ, по умолчанию claude,deepseek,gemini. Используются только ИИ с заданным ключом
- APP_PASSWORD: пароль приложения (защищает ИИ и синхронизацию)


## Документы и резервные копии
- Документы сохраняются в IndexedDB текущего браузера на устройстве.
- Используйте «Резервная копия», чтобы выгрузить документы в JSON, и «Восстановить», чтобы добавить их обратно.
- PDF импортируется как растровые страницы (до 30 страниц и 35 МБ на файл); заметки и штрихи можно наносить поверх.
- Экспорт PDF формирует PDF из изображений страниц и нанесённых аннотаций. Текст исходного PDF после импорта не остаётся отдельным выделяемым текстовым слоем.
- Резервная копия не является облачной синхронизацией: храните её отдельно от устройства.
